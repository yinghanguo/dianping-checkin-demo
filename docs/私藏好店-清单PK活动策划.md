# 「私藏杯 · 上海站」清单 PK 活动策划

> 私藏好店 · 第一期城市 PK 活动策划 V1.1
> 2026 年 7 月 · 上游文档：[产品计划书](./私藏好店-产品计划书.md) · [产品方案 V1.3](./私藏好店-产品方案.md)
> V1.1 修订：① 赛制从 1v1 淘汰赛改为**种草—拔草结算制**（提报 → 3 周收藏/投票/打卡 → 以"收藏用户的真实到店打卡"结算冠军）；② 区域赛道改用点评标准商圈库（10 区 55 商圈）；③ 主题赛道改用 20 个生活场景主题库（覆盖吃喝之外的书店/公园/手艺人等）；④ 投票降级为人气信号与过程分发依据，不进冠军计分。
> V1.2 修订：① 取消成局门槛，全员参赛，改设**授奖线**兜底；② 主会场支持按商圈/主题筛选浏览；③ 主会场承接方案比选（中通 banner / 侧边栏挂件 / 首页下拉二楼）；④ Me 页 banner 位升级为多张横滑 + 2 秒自动轮播；⑤ 奖励体系升级：全场奖上体验型重奖（Asia's 50 Best 香港之旅 / 黑珍珠三钻双人餐 / 霸王餐），用户侧投票零奖励、拔草阶梯抽奖、终审大奖 100 名 × 100 元无门槛券。
> V1.3 修订（选题结构收敛）：① **商圈与主题不再作为"划分赛道、各自决冠军"的分区，而是**——(a) 给创作者的**选题灵感**，(b) 挂在清单上的**归类标签**；比赛为统一打卡榜，全文"赛道"一词均按此理解（灵感 / 归类维度，而非独立赛区）。② 参赛动线：从**「比赛」入口**进清单编辑器时，按清单内容推荐商圈/主题标签供一键挂载；从**「我的」入口**进编辑器保持普通编辑态、不出现挂标签步骤。③ 主题库调整：去掉「理发/美甲/按摩白名单」；「深夜还开着」→「深夜食堂」；「小众博物馆和展」→「小众博物馆展览」；去掉「告别清单」与配套「城市记忆奖」（闭店后用户无法到店，打卡玩法不成立）。④ 奖项更名与口径：全链路"拔草"表述统一为"打卡"；「终审大奖」→「伯乐奖」（突出投票人选中最终打卡王、眼光即品味）；「赛道拔草王」→「打卡王」。

## 一、为什么做清单 PK

产品方案 V1.3 已有「同主题的其他作者私藏」推荐位——同一主题下不同人的答案天然构成比较关系。PK 活动把这个静态推荐位升级为**一场有赛程、有悬念、要用脚投票的全城比赛**：

1. **供给侧**：给创作者一个"值得把清单打磨到最好"的理由。报名门槛即公开门槛，活动本身就是一次全城清单质量大扫除，直接对抗"清单腐烂"。
2. **消费侧**：收藏参赛清单 → 照着去打卡 → 打卡就是给创作者助攻。消费行为第一次有了"参与一场比赛"的意义，把"清单是拿来去的，不是拿来看的"打进用户心智。
3. **关系沉淀**：收藏了参赛清单的用户，就是 Phase 3「订阅—更新」循环的第一批种子关系；比赛结束那天，订阅关系已经建好了。

**一句话定位：官方榜单是统计的答案，私藏杯是让"每个人的答案"接受真实到店的检验——别吵了，用脚投票。**

### 3.3 参赛与授奖门槛

- **全员参赛**：不设成局门槛，所有通过审核的提报清单全部进入比赛，参与所在赛道排名与全场奖评选。
- **授奖线**：赛道「拔草王」需有效拔草打卡 ≥100（拟，可调）方可授奖——参赛无门槛，但奖项不躺赢；未达线赛道的第一名保留荣誉展示与参赛徽章，奖励资源并入下期。
- **重点赛道保供**：平台预判 8–10 条心智强的赛道（南京西路、淮海路、五角场/大学路、咖啡续命站、深夜食堂、面包脑袋巡礼、带爸妈去哪吃、一人食安全区…），提报冷清时定向邀请 KOC，用 AI 选店辅助（只筛店、不代写）快速整理报名；不硬凑烂清单。
- **限报**：每人商圈组、主题组各限 1 份。

## 四、比赛流程

### 4.1 提报期（8/3 – 8/14）

**资格 = 公开清单门槛 + 活动增量要求：**

1. 公开状态的单人清单（共享专辑不可参赛）；
2. 门店 ≥5 家，**每店一句话理由**（无理由不予入围）；
3. 封面及首图为创作者本人照片（商家营销图直接淘汰）；
4. 勾选**《无商业合作声明》**：清单内门店与本人无利益关系，接受核查与公示；
5. 报名时完成一次更新（把参赛变成一次清单大扫除）。

**参赛动线（V1.3）——两个入口，两种编辑态：**

- **从「比赛」入口**（主会场"我要参赛"、Me 页私藏杯 banner）进清单编辑器：编辑器多出一步「挂灵感标签」——按清单内容推荐商圈或主题标签（如整份是咖啡店 → 推荐主题「咖啡续命站」+ 主导商圈），一键挂载，也可从全量灵感库更换；标签随清单进比赛，并展示在清单详情页标题下方。
- **从「我的」入口**（个人主页新建 / 编辑、草稿引导 banner）进编辑器：保持普通编辑态，不出现挂标签步骤。

提报即过商业密度审核（店铺集中新增、多清单异常重合、商户关联账号），8/14 后公示参赛名单。

### 4.2 开赛期（8/15 – 9/6，三周）：收藏 · 投票 · 打卡三线并行

用户侧三个动作，层层递进：

| 动作 | 含义 | 进什么榜 |
|---|---|---|
| **收藏** | "我想照着去" —— 参赛资格线：只有收藏者的打卡才计分 | 收藏数公开展示 |
| **投票** | "我看好它" —— 每人每赛道最多投 3 份（每份 1 票），投票者去过清单内门店的票内部加权（不外显倍数，对齐 V1.3 口径）。**投票本身零奖励**（防灌水），但"投中打卡王"是伯乐奖的资格条件（见第七节） | **人气榜**（过程榜：决定信息流曝光分配 + 人气王奖项，不进冠军计分） |
| **打卡** | "我真的去了" —— 收藏之后对清单内门店的真实到店打卡 | **拔草榜**（结算榜：决定冠军） |

- **按商圈/主题筛选**：主会场支持按商圈（含区级聚合）与主题两个维度筛选浏览参赛清单，用户按自己的生活半径找比赛看；筛选维度即赛道维度。
- 双榜每日更新；开赛首周人气榜撑热度（打卡还在路上），后两周拔草榜接管悬念。
- 投票的赌注感来自**预测**：投中打卡王才有伯乐奖资格——不发券、不给即时奖励，让票保持干净。

### 4.3 计分规则（结算口径，活动页全文公示）

**有效拔草打卡**须同时满足：

1. 打卡者在**打卡之前已收藏**该清单；
2. 打卡发生在开赛期内、门店在清单内；
3. LBS 到店校验 + 实拍照片 + 账号风控分达标；
4. 打卡者非创作者本人及其关联账号/设备。

**计数与防操纵：**

- 人 × 店去重：同一用户对同一门店只计 1 次；
- 每位用户对每份清单最多贡献 **3 家**计分（防超级粉丝一人刷满整份清单）；
- 单店贡献占该清单总分上限 **40%**，超出不计（防单店爆款/商户合谋拉动整份清单）；
- 一次打卡若命中用户收藏的多份参赛清单，各清单均计分（真实到店对每份清单都是真实转化）。

**冠军 = 赛道内有效拔草打卡数第一。** 平局依次看：拔草人数（完成 ≥1 次有效打卡的收藏者数）→ 去过加权后的票数。

## 五、分发触点

| 场景 | 形式 |
|---|---|
| 活动主会场 | 商圈/主题双维筛选 + 双榜实时 + 我的助攻战绩（我为哪些清单贡献了拔草）+ 报名入口；承接方案见下方比选 |
| 信息流 | 「赛道战报」卡（榜首对垒 + 悬念文案"南京西路拔草王之争还差 12 次打卡"）；好友动态：「×× 为一份私藏助攻了 3 家店」 |
| 搜索 | 搜索商圈词/主题词置顶该赛道榜卡 |
| 门店详情页 | 参赛清单收录的门店挂角标：「这家店在 N 份参赛私藏里 · 打卡即助攻」——**店页是拔草计分的临门一脚，全活动最重要的触点** |
| 地图 | 「我收藏的参赛清单」图层：把待拔草门店连成周末路线（复用清单地图模式） |
| Me 页 | 复用现有 banner 位，升级为**多张横滑 + 每 2 秒自动轮播**：创作者报名引导 / 我的拔草进度 / 阶梯抽奖进度各一张，按人群定向展示 |
| 微信分享 | 创作者「帮我守擂，来打卡」拉票卡（直接带清单+门店）；用户「本周末拔草路线」晒卡 |

**主会场承接方案比选：**

| 方案 | 优势 | 代价 | 结论 |
|---|---|---|---|
| 首页中通 banner | 全量强曝光、开发成本低、可分波次投放 | 占商业化资源位；banner 盲区效应，长周期活动后期点击衰减快 | **主入口**：开赛周 + 决胜周两波强投 |
| 侧边栏挂件（悬浮球） | 常驻、随时回访看榜，贴合三周长周期"每日战报"的回访动线；干扰小 | 曝光弱，不能承担冷启动 | **常驻回访入口**：赛程期全程挂 |
| 首页下拉二楼 | 沉浸感与仪式感最强（"下拉进入私藏杯"），空间大可承载双榜+战报+城市感视觉 | 开发成本最高、入口需教育、通常留给 S 级活动 | **可选项**：若定级 S 级则上，否则留给第二期 |

推荐组合：**中通 banner（两波强投）+ 侧边栏挂件（全程常驻）**，二楼视活动定级决定。理由：本活动是三周长周期赛程，"反复回访看榜"比"一次性大曝光"更重要，双入口分别解决冷启动与回访；二楼的沉浸空间在第一期数据验证前属于超配。

## 六、信任与反作弊（本活动的生死线）

计分从投票改为打卡后，攻击面从"刷票"转移到"刷打卡"与"商户合谋"：

1. **打卡真实性**：LBS 半径 + 实拍照片查重 + 风控分；同设备多账号折叠；异常模式（单日计分打卡 ≥5 家、深夜批量打卡）自动降权并人工复核。
2. **商户合谋**：门店侧异常打卡聚集检测（某店计分打卡短期激增且高度指向单一清单）；"到店打卡送菜"类活动一经查实，该店打卡全部剔除；创作者知情参与 → 取消资格并公示。
3. **创作者自刷**：本人及关联账号打卡不计；小号收藏+打卡由设备/关系图谱识别。
4. **准入即审核**：报名清单全量过商业密度识别；疑似商业化拒入围并告知原因。
5. **透明公示**：结算期公示各赛道无效打卡剔除比例与主要原因——让用户看见平台守规则，公示本身就是信任产品。
6. **全程零商业化**：赛道无冠名、清单无推广位、奖励无现金。第一期宁可素一点，也不给"私藏"沾上生意味。

## 七、奖励体系：荣誉打底，体验型重奖封顶；现金零、商户赞助零

### 7.1 创作者侧

| 奖项 | 评定 | 奖励 |
|---|---|---|
| **打卡王** | 有效打卡数第一（须过授奖线） | ①「2026 私藏杯·上海站 打卡王」徽章，永久挂清单头部与个人主页；② 2 周分发加权：搜索置顶 + 店页收录模块首位；③ 受邀与官方共创下期标杆清单 |
| **人气王**（全场 1 名） | 全场总票数第一 | **亚洲 50 最佳餐厅（Asia's 50 Best）香港双人美食之旅**（含机酒 + 2 家上榜餐厅晚餐） |
| **黑马奖**（全场 1 名） | 报名时粉丝数最低但冲进前三 | **黑珍珠三钻餐厅双人晚餐** |
| **转化神**（全场 1 名） | 收藏 ≥100 且收藏→打卡转化率第一 | 全年 12 次霸王餐体验卡（拟） |
| 所有参赛者 | 通过审核即得 | 参赛徽章 + 巡礼周专题轮播 |

### 7.2 用户侧

| 玩法 | 规则 |
|---|---|
| 投票 | **零奖励**——票只代表判断，不代表薅羊毛 |
| 打卡阶梯抽奖 | 活动期内累计有效打卡 **3 / 6 / 10 次**解锁三档抽奖（奖池拟：美食类目满减券 / 大额券 / 霸王餐），越走越值钱 |
| **伯乐奖** | 结算后，在**投中打卡王**的用户中，按有效打卡门店数排序，**前 100 名每人 100 元到店无门槛券**——既要眼光准（投中），又要腿勤（打卡多） |

### 7.3 底线

所有奖品由平台统一采购，**不接受商户赞助或资源置换**——重奖可以有，利益关联不能有。创作者奖励保持"体验型、不可转让、不可变现"，防止"为奖参赛"滑向商业化变形；用户券的发放全部在结算之后，不影响计分。

## 八、指标体系

| 层 | 指标 | 第一期目标（拍板值，供校准） |
|---|---|---|
| 供给 | 提报清单数 / 达标率 / 有提报的赛道覆盖数 | ≥200 份 / ≥60% / ≥30 条 |
| 种草 | 参赛清单收藏总数 / 收藏 UV / 投票 UV | 收藏 UV 5 万+ |
| 拔草（核心） | **有效拔草打卡总数 / 拔草率（收藏者中完成 ≥1 次有效打卡的占比）** | 打卡 3 万+ / 拔草率 ≥15% |
| 增长 | 分享卡站外回流占比 / 回流新客数 | 回流占收藏 UV ≥15% |
| 循环 | 赛后 30 天：参赛清单更新率 / 收藏关系留存 / 订阅召回打开率 | 更新率 ≥50% |
| 信任 | 无效打卡剔除率 / 商户合谋查实数 / 取消资格数 | 剔除率逐周下降并公示 |

北极星对齐：**有效拔草打卡本身就是"经清单到店"**——本活动是第一次大规模、可归因地测量清单到店转化的机会，结算数据直接沉淀为分发权重的真值集。

## 九、风险与对策

| 风险 | 对策 |
|---|---|
| 头部达人粉丝多、拔草总量天然占优（马太） | 每人每清单计分上限 3 家 + 单店 40% 上限压制粉丝浓度；设「转化神」「黑马」奖表彰小而精；巡礼周给非冠军运营位 |
| 打卡造假 / 商户合谋 | 第六节全套；最坏预案：某赛道作弊实锤 → 剔除后重新结算并公告 |
| 前两周拔草数据冷清、比赛没悬念 | 人气榜先行撑热度；战报卡制造差值悬念；周末前推送「你收藏的清单还差 N 次打卡反超」 |
| 三周窗口太长、用户中途流失 | 每周一个运营节拍：W1 种草周（晒收藏）/ W2 冲榜周（战报+反超）/ W3 决胜周（悬念+伯乐奖资格冲刺） |
| 主题组非餐饮 POI 打卡习惯弱（书店/公园） | 店页角标「打卡即助攻」强提示；这些赛道拔草目标单独下调，不与餐饮赛道横比 |
| 冷门赛道只有一两份清单、独苗躺赢 | 授奖线兜底（有效拔草 <100 不授奖，荣誉保留）；重点保供集中在 8–10 条心智强赛道；冷门赛道清单仍参与全场奖评选 |
| 体验型重奖诱发"为奖参赛"投机 | 奖品不可转让、不可变现；人气王依赖全场票数、伯乐奖以真实打卡为条件，攻击成本高于奖品价值；风控同第六节 |
| 投票用户看完不留资产 | 投票动线强制经过收藏选项；赛后向收藏者推送「你助攻过的清单更新了」 |

## 十、与产品路线的衔接 & 下期扩展

- **本期属于 Phase 2（分发期）**：验证清单在高曝光场景下的到店转化与信任耐受度；收藏了参赛清单的用户直接成为 Phase 3「订阅—更新」循环的种子。
- **需要的产品增量**（按优先级）：① 收藏→打卡的归因计分管道（活动结束后即为"经清单到店"常规指标复用）；② 活动主会场与双榜页（含商圈/主题双维筛选）；③ 店页「打卡即助攻」角标；④ 报名与声明流程；⑤ 战报卡；⑥ Me 页多 banner 横滑轮播组件（2 秒自动轮播）。清单本体、收藏、地图模式、分享卡均复用现有能力。
- **原型注**：现有 demo 数据可支撑演示——南京西路（2 份重叠清单）、咖啡续命站（3 份咖啡清单）、深夜食堂（深夜食堂清单）已在库，网球清单可归入「健身替代方案」赛道。
- **第二期候选**：守擂制（本期拔草王接受挑战）、城市德比（上海 vs 成都同主题隔空比拔草率）、用户票选新主题入库。

## 十一、一句话收拢

私藏杯的裁判不是评委也不是票数，是**三周里真实走进店门的那些人**。收藏是心动，投票是站队，打卡才是真爱——只要"票是真的、打卡是真的、清单是干净的"这三条守住，这场比赛就会替产品回答那个最关键的问题：**人的品味，到底能不能把人带到店里去。**
